# dsh-annotate v0.110.2

> 这一版修的都是「文档面板到底在显示哪份文档」，之前 0.106–0.110.1 都有残留问题。建议所有用户升级到 0.110.2 或更新。

## 修了什么

- **文档面板不再闪**（0.107.6 / 0.108.0 / 0.109.0）：文档库兜底不再每拍抢「最新一份」；停靠右侧栏时窗口不再同时渲染（单实例）；轮询只允许当前会话的实例写文档。
- **批注不再挂到别的文档上**（0.107.7）：键对不上时的兜底要求「聊天块 ↔ 磁盘文件」这种键族变化，并且引文 ≥8 字且在本篇只出现一次；搬移批注不再改写 `docKey`。
- **文档不再串会话**（0.110.0 / 0.110.1）：归属按文件目录的会话尾巴判定；没有会话 ID 的老文档不再在每个会话里显示。
- **不再往别的会话目录写副本**（0.110.2）：写盘带上文档来源目录，服务端优先写回原目录。
- **批注抽屉**（0.109.0 / 0.109.1）：卡片默认 3 行截断 + 「展开全部」；新增搜索（引文 / 批注 / 回复 / 文件路径），只过滤显示、不影响发送范围；修了搜索框点不进去。
- **文档停靠**（0.107.0 / 0.107.2 / 0.108.1）：新增「文档停靠在右侧栏」开关（默认关）；停靠时顶栏「文档」把页签推到前面；窗口标题栏有「⇥ 停靠」回到右侧栏。
- **文档窗口**（0.107.1 / 0.107.3 / 0.108.1）：「‹ 收起」不再失效；批注面板永远压在文档窗口之上（统一层级约定）。
