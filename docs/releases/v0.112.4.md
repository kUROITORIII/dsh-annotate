# dsh-annotate v0.112.4

> 右侧栏「文档」页签跟随当前会话——找到宿主真正的传参位置了。

## 修了什么

- 宿主的右侧栏页签是「按会话」的槽位，会话 id 直接挂在组件 props 上；我们以前读的是一个为空的 `props.scope`，于是退化到「上次右键批注的会话」，切会话不跟随。
- 现在优先读 `props.sessionId`，其次 `props.scope.sessionId`；面板取会话顺序改为 页签 scope → docSid → 显式 props → `store.active`。
- 新增一行诊断，重启后可确认宿主给了什么。
