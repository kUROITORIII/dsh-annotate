# dsh-annotate v0.111.0

> 这一版按外部代码审计做了「归属判据」最小修法：不再靠“内容像”猜归属。

## 修了什么

- 文档库里的条目加「可信」标记：只有**本会话聊天里真的扫到过**的才算可信；旧数据里的聊天键条目先标为不可信，不再跨会话显示。
- 入库绝不再覆盖已有 `sid`；切会话瞬间不入库。
- 删掉两处「认领」（内容相同就改 sid、无 sid 就认领给当前会话）。
- 写盘改白名单：只有本地编辑或本会话聊天采纳才落盘，从库/磁盘采纳的一律不写。
- 服务端跨目录写盘不再污染目标目录 `_session.json` 的 sid。

git pull
