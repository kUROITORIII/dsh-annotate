# dsh-annotate v0.112.0

> 文档库按会话分桶（schema 3）：别的会话的文档在结构上就拿不到，不再靠判据猜归属。

## 修了什么

- 文档库从全局一份改成 `docs[会话][键]`，读写各只有一个入口。
- 不同会话里同名的聊天块键不再互相覆盖、也不再被存到别人名下。
- 切会话瞬间（900ms 内）不入库；历史版快照按会话隔离；没有会话 id 的文档一律不收。
- 服务端拒绝跨会话目录写盘（409）。
- 新增启动诊断两行，写进 `~/.dsh/annotate-client-debug.log`。

## 数据迁移

首次启动自动把旧 `docLibrary` 拆进各会话；旧字段原样保留一个版本，回滚到 0.111.x 无损。

## 升级

```bash
git pull
# 然后重启 DSH
```
