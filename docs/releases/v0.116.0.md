# dsh-annotate v0.116.0

P2：Excel（xlsx）能打开了。

- 会话文档目录里的 **xlsx** 以只读表格打开；多张工作表时顶部切换。
- 共享字符串、内联字符串、日期、合并单元格、公式（显示缓存值，格子上标 `ƒ`，悬停看公式）都按原样显示。
- 点单元格写批注，发出去写成 `文件名 · Sheet1!B3`。
- 工具栏「导出 ▾」→「批注.csv」：文件 / 工作表 / 单元格 / 值 / 批注 / 状态 / 回复，Excel 双击不乱码（csv 文件也能用）。
- 「改后.xlsx」（把已解决的批注写回单元格）下一版再做，下拉里先置灰。
- 坏文件或老 `.xls` 会提示「这个表格解析不了」，不白屏。

升级须知：本版改了宿主 `index.js`，**需要重启 DSH**；客户端热重载。
