# dsh-annotate v0.113.0

> 终版设计书 v3 · P0：性能。数据格式不变（schema 3）。

## 改了什么

- **缩放/拖动不再卡**：去掉全部毛玻璃（`backdrop-filter`，6 处）；拖动/拉伸按帧合并提交；拖动和窗口缩放期间关掉阴影与过渡。
- **扫描改事件驱动**：聊天有变化、切会话、开面板、窗口聚焦、文档变长时才扫；流式生成期间 250ms 一次；空闲时 1.6 秒兜底；磁盘对账仍保证 4 秒内出现新文件。`window.__dshaScanMode('poll')` 可切回老轮询对照。
- **性能日志**：每 10 秒一行写进 `~/.dsh/annotate-client-debug.log`（只有数字）；`window.__dshaPerf()` 可在控制台查看。
- **落盘减重**：回滚用的旧文档库只序列化一次，不再每次落盘都重算；字段仍然保留，回滚到 0.111.x 无损。

## 观感变化

面板、批注框、工具条背景从毛玻璃改成 97% 实色。
