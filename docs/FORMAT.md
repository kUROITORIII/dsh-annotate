# 对话文档块格式（dsh-doc 契约）

**对应插件版本：0.113.9** ｜ 语法一改就要改这一行，并通知使用侧同步（见文末）。

这份文档是 `dsh-doc` 格式的**唯一真相源**。插件的解析器按它实现，`doc-review` 技能按它使用；
两边不一致时以本文件为准——改语法的人负责同时改这里和版本号。

## 外形

**普通围栏**（三个反引号，后面什么都不写），块内**第一行单独**写 `dsh-doc`，正文从第二行开始：

````
```
dsh-doc
# 标题

正文……
```
````

插件认的是**块内第一行的哨兵**，不是围栏的语言标记。

## 文档里要放代码块/图卡时：外层用四个反引号

`dsh-doc` 正文里如果自己带 ` ``` `（代码块、```svg 图卡），**外层围栏必须写四个反引号**，
否则内层的三个反引号会把整篇文档提前截断——后面的段落掉到围栏外，聊天里变成独立代码块，
右侧文档只剩前半篇（2026-11-26 就踩了这个坑）。

````
````
dsh-doc
# 标题

正文……

```js
const a = 1
```

```svg
<svg viewBox="0 0 10 10"></svg>
```

后面继续写，仍然算这份文档。
````
````

规则一句话：**外层反引号数量 > 内层最多的那一组**。
## 全量与增量

| 哨兵 | 语义 |
| --- | --- |
| `dsh-doc` | **整篇替换**：这一份就是全文，之前那份作废（旧版留在文档库里可回看） |
| `dsh-doc+` | **只追加**：只发新增的那几段，不重发全文；插件把它接在当前文档末尾 |

同一个会话里可以有**多份** `dsh-doc`，各是各的文档（文档库按「聊天节点 + 标题」区分），
最新出现的那份是「最新」。

## 禁止项

**不要把哨兵写进围栏的语言位**，也就是不要写成：

````
```dsh-doc
# 标题

正文……
```
````

DSH 会把围栏后面那串当 language token 吞掉：块里没有哨兵、也没有语言类名（实测：往上打四层类名只有 `_plain_* / _content_* / _block_* md-code-block / _card_*`，一个 language-* 都没有），
插件就只把它当普通代码块——**右侧不会出现文档**，用户会以为"文档打不开"。
这个坑已经踩过两次（2026-11-23、2026-11-24）。

代码里还留着一条「认 language-dsh-doc 类名」的分支（docMode()）：在**当前 DSH 上它永远不会命中**，属于防御性死代码——万一以后宿主改回保留语言类名，它能自己救回来。别依赖它。

## 两个最小示例

**正确**（右侧会出文档，标题「最小可用示例」）：

````
```
dsh-doc
# 最小可用示例

一行正文。
```
````

**错误**（哨兵在语言位，右侧什么都不出）：

````
```dsh-doc
# 最小可用示例

一行正文。
```
````

两者在聊天里看起来几乎一样，区别只在右侧有没有文档——这正是它容易被忽略的原因。

## 图卡：```svg（v0.64 起）

文档里可以放一张「图卡」：**围栏语言写 `svg`，块内就是一段 `<svg>…</svg>` 源码**。
插件把它画成卡片（标题条 + 「下载 PNG」），不进代码块样式，也不参与批注。

````
```svg
<svg viewBox="0 0 760 556" aria-label="S3 影院平面示意">
  <rect x="128" y="60" width="504" height="270" fill="none" stroke="#8a8a8a"/>
  <text x="380" y="408" text-anchor="middle">门厅</text>
</svg>
```
````

规则：

- **必须是完整的内联 SVG**，有 `<svg>` 和 `</svg>`；缺一半会被拒绝，卡片显示「图块渲染不了：…」。
- **不跑脚本**：渲染前会删掉 `<script>`、`foreignObject`、`<image>/<iframe>/<embed>/<object>`、所有 `on*` 事件；
  `href` 只留同文档锚点（`#id`），外链和 `javascript:` 一律删。想画渐变、箭头，用 `<defs>` + `url(#id)`。
- **宽高从 `viewBox` 取**，没有就按 760×556。给 `aria-label`（或 `<title>`）当卡片标题和文件名。
- **导出 PNG 是白底两倍分辨率**，贴进 Word / PPT 不会变透明块。
- 只接受静态图；要「改参数重画」得让模型重发整块 SVG（插件不做 JSX 转译，零构建引不进 Babel）。
## 文档面板支持的 Markdown（v0.71 起）

| 写法 | 渲染 | 备注 |
| --- | --- | --- |
| `#`…`######` | 标题 1–6 | v0.71 起支持 h5/h6 |
| `- ` / `1. ` | 列表 / 有序列表 | 有序编号保留；缩进 2 空格算一层 |
| `- [ ]` / `- [x]` | 任务项 ☐ / ✓ | 只显示，不改文档 |
| `>` | 引用 | 嵌套 `> >` 只剥一层 |
| `---` / `***` / `___` | 水平线 | v0.71 起；以前显示成一段文字 |
| ` ``` ` / ` ```js ` | 代码块 | 语言名显示在右上角 |
| ` ```svg ` | 图卡（可下载 PNG） | 见上一节 |
| `\|a\|b\|` + `\|---\|` | 表格 | 单元格里 `\|` 与反引号内的 `\|` 都不裂列 |
| 其余 | 段落 | |

**不支持**（会原样显示，别用）：图片 `![]()`、脚注、定义列表、HTML 块、数学公式、mermaid（当普通代码块）。
任务项、表格、图卡**不参与批注**；其余段落都能划句。

## 落盘与增量更新（v0.43 起）

文档在聊天里出现之后，插件会把它**同时落盘**：

```
${DSH_HOME}/annotate-docs/<会话尾 8 位>/<文档标题>.md
${DSH_HOME}/annotate-docs/<会话尾 8 位>/_session.json   # 完整会话 id + 标题→文件名映射
```

- 文件名用**文档标题**（Windows 非法字符 `\ / : * ? " < > |` 换成 `-`，重名加 `-2`，超长截 40 字；首见即定名）；
- 右侧面板优先显示落盘的那份，所以**文档滚出聊天、清空文档库都不会丢**；
- 文档下拉里可以「打开文档文件夹」「在编辑器里打开」「删除本会话的文档文件」「清理已删会话的文档文件」。

**模型侧更新文档，优先用这三个工具（增量，不必重发全文）**：

| 工具 | 用途 | 约束 |
| --- | --- | --- |
| `doc_read` | 读当前会话文档全文 | 改之前先读，锚点要逐字一致 |
| `doc_replace {anchor, text}` | 替换一段 | `anchor` 必须在全文**唯一**；重复或找不到直接拒绝 |
| `doc_append {text}` | 末尾追加 | 文档不存在时用它建第一份 |

聊天里的 `dsh-doc` / `dsh-doc+` 块**仍然有效**（新文档、一次性文档走它），但**改已有文档**优先用工具：
整篇重发既费 token，又会让段落重切、批注锚点漂。

**回退**：删掉 `annotate-docs` 里对应文件夹即可；关掉落盘不影响插件其它功能。
