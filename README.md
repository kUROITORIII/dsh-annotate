# 划句批注 · dsh-annotate

**选中一句话 → 右键 → 写批注 → 攒着 → 一次发给 AI**，让它逐条回答或逐处修改；
**对话文档**还能在右侧面板里读、划句批注，并把结论写回文档。

对标 Claude 文档里的「划句批注」，落在 DSH 的**聊天消息**和**对话文档**上。

---

## 三个入口

| 入口 | 位置 | 做什么 |
| --- | --- | --- |
| **右键划句** | 聊天气泡或文档正文里选中一句 → 右键 | 弹批注框：问一句 / 要改 |
| **顶栏「批注 N」** | 聊天顶栏 | 看攒了多少条、发送、筛选、导出 |
| **顶栏「文档」** | 聊天顶栏 | 打开右侧文档面板（有文档时按钮亮蓝边＋呼吸点） |

斜杠命令：`/doc` 让模型把刚才的讨论整理成文档；`/doctab` 直接把右侧文档页签推到前面（需 `dsh-better-sidebar`）。

## 一次典型的批注

1. 选中一句话（**必须已经输出完**，流式中的内容锚不住）；
2. 右键 → 「问一句」或「要改」→ 写一句意见 → `Ctrl+Enter` 添加；
3. 反复几次，顶栏数字累加；
4. 点「发送 N 条」——**12 条一批**，每条带 `【B1-2】` 这样的编号；
5. 我逐条回答，插件按“末尾 24 字 + 批次数”把回答配回对应批注，卡片由**蓝**变**绿**。

「问一句」和「要改」分开是有意的：不问清楚就动手，是最常见的返工。

## 文档面板

`dsh-doc` 围栏的文档会显示在右侧：标题层级、列表/有序列表、任务项、引用、水平线、表格、代码块、`svg` 图卡都能渲染，段落可划句批注。

- **三色语义**：蓝＝未回复（或发送中）、绿＝已回复、橙＝原文被改过（批注记录的那句话和现在的正文对不上）；
- 找不到原文时，卡片变橙红并给「重划」，正文对应段落右上角出现橙色角标；
- 批注锚点＝`文档键 + 段号 + 字符偏移 + 引文`；文档重生成、段落挪动后按“最长公共子串”重新定位，并**把新位置写回存储**（重启不丢）。

### 结论回写（0.100 起）

一条文档批注有了 AI 回复之后，线程卡上会出现：

| 按钮 | 行为 |
| --- | --- |
| **追加到段后**（主） | 回答变成**引用块**加在那段之后，原句保留 |
| 写回这段（次） | 用回答**替换**原句，需点两次确认 |

默认什么都不做，**你点才写**。代码块 / 表格 / 图卡里的批注不能写回（会破坏结构），历史版文档、`dsh-doc+` 续写拼接的文档也不能写回。

## 设置

入口：**插件 → dsh-annotate 这一行 → 配置**（不在设置页，也不在行上直接改）。

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 文档出现时自动打开 | 开 | 会话第一次出现文档时自动推出页签 |
| **文档存放目录** | 留空 | 留空＝`${DSH_HOME}/annotate-docs`；只影响之后落盘的文档 |
| 默认字号 | 15（12–21） | 文档字号；面板里 A-/A+ 手动调过后以本地为准 |
| 回复锚点队列长度 | 4（1–4） | 多批批注同时等回复时，记住最近几条消息末尾用于配对 |
| 右键唤出范围 | 开 | 关掉后必须先划中一句话再右键 |
| 划句表情 | `👍=对，就这么做 / ❌=不对，换个做法` | 一行一个「表情=含义」，点表情直接把含义连同选句发出去 |

## 文档落在哪

```
${DSH_HOME}/annotate-docs/<会话尾 8 位>/<文档标题>.md
${DSH_HOME}/annotate-docs/<会话尾 8 位>/_session.json   # 标题→文件名映射
```

文件名用标题（Windows 非法字符替换、重名加 `-2`、超长截 40 字）。文档滚出聊天、清空文档库都不丢；模型用 `doc_read / doc_replace / doc_append` 增量改，不必重发全文。

文档下拉里：分批历史版本、切历史版（只读）、打开文件夹、在编辑器里打开、整理（只清显示 / 删本会话 / 删已删会话）。

**格式契约**见 [docs/FORMAT.md](docs/FORMAT.md)——哨兵写法、外层围栏必须比内层多、全量/增量语义、禁止项、支持哪些 Markdown。语法变更要同步那份的版本号。

## 不能批注的地方

DSH 官方对“文字手势”的限制，不是本插件的 bug：

- **正在生成中的回复**（流式输出）——没定型，锚不住；
- 工具卡、注入上下文、代码块里的控件；
- Markdown 里的链接/按钮（右键会走文件/链接菜单）；
- 表格、图卡**不参与批注**（表格单元格划句尚未实现）。

## 已知限制

- 批注存在**本地** `localStorage`（按会话隔离），不上传；换机器/清缓存会丢；
- 文档批注的高亮跨版本能不能留住，取决于引文还能不能匹配上——整段重写就会失效（会明确标橙，不静默消失）；
- 长文档（段数过万）会卡，尚无虚拟滚动；
- 导出只有 Markdown / CSV，没有 PDF / docx。

## 发版清单

1. `ELECTRON_RUN_AS_NODE=1 <electron> --check client.js` 与 `--check index.js` 都过；
2. `<electron> .lab/test-payload.cjs` 全绿（当前 **246** 条）；
3. 三处版本号一致：`package.json` / `PLUGIN_VERSION` / `docs/FORMAT.md` 顶部；
4. `Copy-Item annotate annotate.backup-<版本>-<日期> -Recurse` 先备份；
5. 重启 DSH（`ctrl+r` 只重载客户端，改了 `index.js` 必须重启），用**痕迹**确认真的重载了（进程启动时间晚于 `client.js` 修改时间）；
6. 语法有变 → 改 `docs/FORMAT.md` 顶部版本号，并通知使用侧同步 `~/.dsh/skills/doc-review/SKILL.md`（那份由使用侧维护）。

## 仓库结构

```nclient.js / index.js      插件两半（浏览器 + 宿主）
package.json             dsh 清单（files 白名单决定发什么）
docs/FORMAT.md           dsh-doc 格式契约（随包发布）
dev/                    开发过程文档：HANDOFF / NEXT / PLAN / RESEARCH（**不进包**）
```
